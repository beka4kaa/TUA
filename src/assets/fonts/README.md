# Gilroy Font Files

Place the Gilroy font files here:

## Required files:
- `Gilroy-Regular.woff2` - Regular weight (400)
- `Gilroy-Medium.woff2` - Medium weight (500)
- `Gilroy-SemiBold.woff2` - Semi-bold weight (600)
- `Gilroy-Bold.woff2` - Bold weight (700)

## Usage
The font is configured in `src/app/layout.tsx` using `next/font/local`.

## Fallback
Until Gilroy is added, the project uses **DM Sans** as a fallback (very similar geometric sans-serif).

## Note
Gilroy is a premium font. Make sure you have proper licensing before using in production.
